## Production work

### Customer profile aggregation & AI summarization

Built the UiPath Studio Web review application with populated data, charts, reports and tables; two key RPA processes; Maestro orchestration; and LLM agent prompts, validations and tests.

The solution brings current data and AI summaries into one review interface. An operator checks the information and approves it before proceeding. PII is processed within the enterprise environment.

**Reported outcome: approximately 70% less operator time spent collecting and verifying data**, compared with the previous process involving three platforms and eight Redshift scripts. Reviewers receive current data instead of relying on two scheduled daily refreshes.
